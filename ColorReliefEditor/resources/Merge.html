This tab creates full-size hillshade and color images and then merges them into a relief image.

Instructions

Create: Click Create to generate the final full-size image for this layer.

View: Launches an external viewer to display the full-size image. The default system viewer is the default but QGIS is highly recommended. You can set your preferred viewer in the expert mode Settings tab

Expert Settings

  • Calc: The calculation to combine the hillshade (A) and color (B) layers. The default is a weighted composite multiply. Must start with --calc=
  • Quiet Mode Options:
  • -q Minimal output.
  • -v Verbose progress
  • --version Show detailed progress and gdal version

Publish To: (Optional) Destination folder for the final image. Enter a full path in the field provided.

Cleanup: Deletes intermediate files for the current layer to save space. These files are useful for re-creating images faster, so use this only when you're finished.

Use the Layers Tab to switch the active layer

If you have multiple layers, run Create for each layer.

Notes

The output window primarily shows progress. You only need to review the output if something goes wrong.

The app will display 'Done' when the image is successfully built. Click View to view it externally.

"Create" runs multiple processes in parallel, which can result in mixed or garbled output text.
